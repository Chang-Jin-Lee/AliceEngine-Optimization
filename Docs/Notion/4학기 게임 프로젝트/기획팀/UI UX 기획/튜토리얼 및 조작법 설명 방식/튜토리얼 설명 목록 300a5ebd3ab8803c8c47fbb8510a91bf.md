# 튜토리얼 설명 목록

# 웨폰게이지

패링이 아닌 가드를 한 경우, 웨폰게이지를 소모한다.
웨폰게이지가 0이 될 경우, 웨폰 브레이크가 발생한다.
웨폰 브레이크 발생 이후 일정 시간 동안 회피만 가능해진다.
일정 시간 이후 웨폰게이지는 100% 회복된다.
웨폰게이지는 공격 적중 시 일정량 회복된다.

# 가드/패링

상대 공격을 마우스 우클릭을 눌러 웨폰 게이지를 소모해 가드 할 수 있다.

정확한 타이밍에 가드한 경우, 패링이 발동되어 적의 강인도를 대폭 감소시킬 수 있다.
웨폰 브레이크 시 일정 시간 동안 공격/가드가 불가능해진다.

# 광폭화

Q를 누르면 웨폰게이지를 일정량 소모하여 광폭화 상태에 진입할 수 있다.
(소모할 웨폰게이지가 없으면 사용 불가)
광폭화 상태에서는 기본 공격이 캔슬되지 않으며, 공격이 1회 추가된다.
광폭화 상태에서 차지 공격 사용 시 '난무'를 발동할 수 있다.

# 힐

R 키를 홀드해 웨폰 게이지를 소모하여 플레이어 체력을 회복할 수 있다.

# 라스트 스탠딩

플레이어가 사망에 이르는 데미지를 입었을 때, 전투에서 단 한 번 보스의 특수 공격을 패링하여 부활할 수 있다. (단, 웨폰브레이크 상태에서는 발동하지 않는다.)
패링에 성공할 경우 웨폰게이지를 소모하여 플레이어 체력이 즉시 회복된다.
