집에 돌아가는데 창진님께서 말씀하시건대

실행하는 배치파일에서 cmake build 하는걸 같이 수행하면 되지 않냐고

그래서 AliceEngine.bat파일을 수정했다

- 기존 코드
    
    ```cpp
    @echo off
    setlocal
    
    rem "현재 경로(CD)" 기준으로 실행 파일 경로 구성
    set "BASE=%CD%"
    set "EXE=%BASE%\AliceEngine\build\bin\Release\Launch.exe"
    
    if not exist "%EXE%" (
      echo [ERROR] 실행 파일을 찾을 수 없습니다:
      echo         "%EXE%"
      echo.
      echo 현재 경로: "%CD%"
      pause
      exit /b 1
    )
    
    rem 새 창으로 실행 (현재 bat에 전달된 인자도 그대로 전달)
    start "" "%EXE%" %*
    
    endlocal
    
    ```
    
- 바뀐 코드
    
    ```cpp
    @echo off
    setlocal
    
    rem bat 파일 위치를 기준으로 루트 지정
    set "ROOT=%~dp0"
    rem 끝의 \ 제거
    if "%ROOT:~-1%"=="\" set "ROOT=%ROOT:~0,-1%"
    
    set "EXE=%ROOT%\AliceEngine\build\bin\Release\Launch.exe"
    set "SCRIPTS=%ROOT%\AliceEngine\ScriptsBuild"
    set "BUILD=%SCRIPTS%\build"
    
    if not exist "%EXE%" (
      echo [ERROR] 실행 파일을 찾을 수 없습니다:
      echo         "%EXE%"
      pause
      exit /b 1
    )
    
    rem cmake 존재 확인
    where cmake >nul 2>nul
    if errorlevel 1 (
      echo [ERROR] cmake가 PATH에 없습니다.
      echo         CMake 설치 또는 PATH 추가가 필요합니다.
      pause
      exit /b 1
    )
    
    rem 캐시/빌드 폴더 삭제 (경로 불일치 방지)
    if exist "%BUILD%" (
      rmdir /s /q "%BUILD%"
    )
    
    rem Configure
    cmake -S "%SCRIPTS%" -B "%BUILD%"
    if errorlevel 1 (
      echo [ERROR] CMake configure 실패.
      pause
      exit /b 1
    )
    
    rem Build (Release)
    cmake --build "%BUILD%" --config Release --target AliceScripts
    if errorlevel 1 (
      echo [ERROR] CMake build 실패.
      pause
      exit /b 1
    )
    
    rem 실행
    start "" "%EXE%" %*
    
    endlocal
    
    ```
    

이렇게 설정하고 cmake를 설정한 폴더를 지웠더니 잘 된다.

추가적으로 AliceEngine\build 내부에 있는 폴더는 bin, release 폴더를 제외하고는 전부 지워서, 용량을 최소화 했다.

내 컴퓨터에서 빌드가 되는 것을 확인하고 BUILD를 .7Z로 만들어서 압축해서 RELEASE파일을 올렸다.
