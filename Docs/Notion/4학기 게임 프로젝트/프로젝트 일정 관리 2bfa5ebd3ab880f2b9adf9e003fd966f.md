### **템플릿 사용 방법**

- 목차
    - 템플릿의 전체 목차를 한눈에 확인하고, 클릭 한번으로 해당 위치로 이동할 수 있습니다.
- 빠른 작업
    - 각 팀별로 새로운 프로젝트를 데이터베이스에 추가하는 버튼 모음입니다.
    - 버튼 클릭 시 해당 팀/부서가 자동으로 입력된 새로운 페이지가 자동으로 생성됩니다.
- 팀 컬러 한눈에 보기
    - 각 팀별로 지정된 색상을 한눈에 확인할 수 있습니다. 팀 컬러는 빠른 작업 버튼, 주관 부서 및 협력 부서 속성에 반영되어 있습니다.
    - 기본으로 제공되는 팀별 색상이 마음에 들지 않으신다면, 데이터베이스의 “주관부서”, ”협력부서” 옵션을 다른 색깔로 바꾸어 활용해보세요.
- 전체 프로젝트
    - 모든 팀의 프로젝트를 한곳에서 확인할 수 있는 데이터 허브입니다.
    - 프로젝트 제목, 주관 부서, 협력 부서, 상태, 우선순위, 시작일, 마감일, 책임자, 실무자 등의 속성을 제공합니다.
    - 프로젝트 시작 버튼을 클릭하면, 상태 속성이 자동으로 “진행 중”으로 변경되며 시작일 속성도 버튼을 클릭한 시점으로 자동 변경됩니다.
- 운영기획 캘린더
    - 운영기획과 관련된 3개 팀의 프로젝트 캘린더입니다.
    - Admin 탭에서는 전략경영팀, FA 탭에서는 재무회계팀, HR 탭에서는 인사팀의 주관/협력 프로젝트를 확인할 수 있습니다.
- 개발 캘린더
    - 개발과 관련된 3개 팀의 프로젝트 캘린더입니다.
    - FE 탭에서는 프론트엔드팀, BE 탭에서는 백엔드팀, UI·UX 탭에서는 UI·UX 팀의 주관/협력 프로젝트를 확인할 수 있습니다.
- 마케팅·콘텐츠 캘린더
    - 마케팅과 관련된 3개 팀의 프로젝트 캘린더입니다.
    - Marekting 탭에서는 마케팅팀, Content 탭에서는 콘텐츠팀, CS 탭에서는 고객관리팀의 주관/협력 프로젝트를 확인할 수 있습니다.
