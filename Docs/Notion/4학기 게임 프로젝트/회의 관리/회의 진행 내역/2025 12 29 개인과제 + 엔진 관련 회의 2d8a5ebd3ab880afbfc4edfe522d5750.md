    ## 12.29 (4학기) 회의 요약
    
    ### 1. 공통 사항
    
    - 화요일 저녁 이후 **추가 회의 1회 더 진행 예정**
    - 엔진 레포지토리는 현재 **Private**
        - 초기 안정화 부족 및 에러 다수
        - **프로젝트 시작과 동시에 Public 전환 예정**
        - Public 전환 시 **포트폴리오 사용 가능**
    - 향후 **2주간 내부적으로 데모 게임 제작**
    - 커밋 메시지와 문서화는 **최대한 자세히 작성**
        - 의미 없는 코멘트(잡소리)는 제외
        - 수정 시 “무엇을 왜 바꿨는지” 공유 필수
    - 엔진 수정 시 주의 사항
        - **자신이 만든 영역은 수정 가능**
        - 코어 영역(리플렉션, 월드 트랜스폼 관리 등)은 **임의 수정 금지**
        - 변경 필요 시 반드시 사전 공유
    
    ---
    
    ### 2. 엔진 관련
    
    ### 개인 과제 현황
    
    - **한승규**: 완료 (물리 BVH → App: 마우스 피킹, BVH)
    - **안성빈**: 톤매핑 진행 중 + 알고리즘1 + 프로그래밍심화1
    - **조강진**: D3D 3개, HDR, 톤매핑, 디퍼드
    - **이창진**: 전부 완료
    
    ### 향후 엔진 활용 방향
    
    - **엔진 구조 설명 및 시연 예정**
    - 작은 FBX 테스트 씬 존재
        - 캐릭터(라피)가 이동 및 점프하는 데모
        - 해당 씬을 기반으로 기능 확장
    - 실험/테스트 항목 예시
        - 물리 오브젝트 배치
        - 캐릭터에 캡슐 콜라이더 적용
        - 충돌 및 밀림 동작 확인
    - 문제 발생 시
        - 직접 수정 가능하면 수정
        - 그렇지 않으면 **이슈 등록**
        - 변경 계획은 사전에 공유(카톡 등)
    
    ### 엔진 시스템 관련 설명 (요약)
    
    - 리플렉션 및 IMGUI 연동 기본 구조는 구현됨
    - Unity 유사 구조:
        - 월드 오브젝트를 Inspector에 드래그하여 참조 등록 가능
        - 예: UIManager가 Player Character 참조
    - 월드 클래스 및 스크립트 컴포넌트를 자주 보게 될 예정
        - 상세 설명은 추후 진행
    
    ---
    
    ### 3. 아트 관련
    
    - **이번 주 내 아트 작업 마무리 목표**
    - **이권우**
        - 5차례 컨택 실패
        - 윤수 측에 참여 의사 전달
    - **윤수**
        - 권우 참여에 대해 무관 입장
        - 서주형과 프로젝트 참여 가능성 언급됨
    
    ---
    
    ### 4. 개인별 추가 진행 사항
    
    - **조강진**
        - 이번 주까지 과제 완료해야 파티클 셰이더 작업 가능
    - **안성빈**
        - 튜토리얼 App에 UI 추가 예정
    
    ---
    
    ### 5. 기타
    
    - 엔진 시연회는 **진행하지 않을 가능성 큼**
    - 기획 교수 / 프로그래밍 교수 간 협업 구조 연결되지 않은 상태
    - 프로젝트 시작 시 구조 개편 예정
    - 강진은 콘텐츠 측면 기여 비중이 크므로 **과제 조기 완료 요청**
