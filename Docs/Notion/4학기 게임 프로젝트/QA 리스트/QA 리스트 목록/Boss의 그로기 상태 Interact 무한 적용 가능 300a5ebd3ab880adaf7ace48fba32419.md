# Boss의 그로기 상태 Interact 무한 적용 가능

상태: 최종컨펌
분류: 조작
담당자: 승규
작성자: 강진 조
재현 방법: 보스의 게이지를 모두 채워 그로기 상태로 진입 → 좌클릭으로 Interact → 보스가 넘어지고 일어나는 애니메이션에서 좌클릭 → 다시 Interact 적용 빈벅
