# 데칼

# 🎨 Decal System (DX11 Deferred)

> **개요**
> 

EGOSIS 엔진에 구현된 **Deferred Decal System**의 기술 명세 및 사용 가이드입니다.

DX11 기반의 Deferred Rendering 파이프라인 위에서 **DBuffer 방식**을 사용하여 벽이나 바닥에 스티커처럼 텍스처를 투영하는 기능을 다룹니다.

---

## 1. 핵심 컨셉 (Concept)

### 💡 "붙이는 게 아니라 쏘는 것이다"

데칼은 메쉬 표면에 직접 텍스처를 바르는 것이 아닙니다. **가상의 빔 프로젝터(Decal Box)**가 쏘는 빛이 물체에 맺히는 원리와 같습니다.

1. **Volume Projection**: 데칼은 큐브(Box) 형태의 볼륨을 가집니다.
2. **Inverse Projection**: 화면의 픽셀(Depth) 위치를 역추적하여, 이 픽셀이 데칼 박스 안에 있다면 텍스처를 입힙니다.
3. **Deferred Processing**: GBuffer가 완성된 후, 별도의 패스에서 처리하여 기존 지오메트리를 수정하지 않고도 텍스처를 덧입힙니다.

---

## 2. 렌더링 파이프라인 흐름

렌더링은 크게 3단계로 이루어집니다. **DBuffer(Decal Buffer)**를 사용하여 GBuffer를 오염시키지 않고 색상을 합성하는 것이 핵심입니다.

### ① GBuffer Pass (기존)

- 일반 메쉬들을 렌더링하여 Albedo, Normal, Depth 등을 GBuffer에 기록합니다.

### ② Decal Pass (신규 추가)

- **Target**: `DBuffer` (현재는 RGBA8 포맷의 Albedo 1장 사용)
- **Process**:
    1. DBuffer를 `(0,0,0,0)`으로 클리어.
    2. 데칼 엔티티들의 **Bounding Box**를 그립니다.
    3. **Pixel Shader 로직**:
        - Depth Buffer에서 월드 포지션을 복원.
        - World 좌표를 Decal Local 좌표로 변환.
        - 박스 범위(`0.5 ~ 0.5`) 밖이면 `discard`.
        - **Premultiplied Alpha** 방식으로 DBuffer에 색상 누적.

### ③ Deferred Light Pass (합성)

- 조명 연산 시, GBuffer의 색상과 DBuffer의 색상을 합칩니다.
- **합성 공식**:High-level shader language
    
    # 
    
    `// DBuffer의 알파가 이미 RGB에 곱해져 있다고 가정 (Premultiplied)
    FinalBaseColor = BaseColor * (1.0 - DecalAlpha) + DecalColor;`

## 3. 데이터 구조: `DecalComponent`

위치와 회전은 `TransformComponent`를 공유하며, 데칼 고유 속성은 아래와 같습니다.

| **속성** | **설명** | **비고** |
| --- | --- | --- |
| **Enabled** | 데칼 활성화 여부 |  |
| **Texture Path** | 투영할 텍스처 경로 | RGBA (A는 마스크) |
| **Color** | 틴트(Tint) 색상 | 텍스처와 곱 연산 |
| **Opacity** | 전역 불투명도 |  |
| **Sort Order** | 렌더링 순서 | 겹칠 때 우선순위 |
| **UV Scale/Offset** | 텍스처 타일링 및 이동 |  |

## 4. 에디터 기능 및 디버깅

### 🛠 Inspector

- **전용 UI**: 텍스처 Drag & Drop 지원.
- **중복 방지**: 일반 레지스트리 인스펙터 목록에서 제외하고, 전용 탭에서만 보이도록 처리.

### 👁️ Debug View

- **DBuffer Visualization**: 뷰포트 상단 `View` 메뉴에서 **Decal DBuffer**를 선택하면 데칼 레이어만 따로 볼 수 있습니다.
- **Volume Draw**: `Show DebugDraw` 활성화 시, 데칼의 투영 범위가 **와이어프레임 박스**로 표시됩니다. (선택 시 하이라이트)

## 5. 사용 가이드 (Quick Start)

1. 씬(Scene)에 빈 엔티티 생성.
2. `DecalComponent` 추가.
3. **Albedo Texture**에 원하는 이미지(png 등) 연결.
4. 트랜스폼 툴을 이용해 데칼 박스를 벽이나 바닥에 겹치게 배치.
    - *Tip: 박스의 화살표 방향(Look Vector)이 텍스처가 투영되는 방향입니다.*

## 6. 개발 이슈 및 해결 (Troubleshooting)

개발 과정에서 발생했던 문제와 해결책을 기록합니다.

### 🐛 Issue 1: 인스펙터 중복 출력

- **현상**: 인스펙터 창에 'Decal' 섹션이 두 번 나오는 현상.
- **원인**: `DecalComponent`가 전용 그리기 함수와 자동 생성 레지스트리 양쪽에서 모두 호출됨.
- **해결**: 레지스트리 기반 렌더링 루프에서 `DecalComponent` 타입을 예외 처리(`if statement`)하여 제외함.

### 🐛 Issue 2: ImGui ID 충돌

- **현상**: 버튼을 누르거나 슬라이더를 조절할 때 다른 컴포넌트가 반응하거나 에러 로그 발생.
- **원인**: 여러 컴포넌트에서 동일한 라벨 이름("Color", "Opacity")을 사용하여 ImGui 해시가 충돌.
- **해결**: `PushID("DecalComponent")`로 ID 스택을 분리하고, 라벨 뒤에 `##Decal` 접미사를 붙여 고유성 확보.
