# 히트박스 제작하기 + 판정 넣기

판정 시간 0.0 ~ end 기준으로 각 클립마다 넣어주면 되고

클립 1개에 여러 판정을 지정할 수 있음
slot 0은 기본 무기 판정이고

이외는 움직이는 히트박스 중에 선택하는거임

---

## 1) WeaponTrace 준비 (히트박스 단위 엔티티)

**목표:** “무기/발/몸통”처럼 *판정 단위*마다 `WeaponTraceComponent`가 붙은 엔티티를 따로 만든다.

- `WeaponTraceComponent` 붙이기 (판정 단위마다 1개 엔티티)
    - 예: 무기용 Trace, 발차기용 Trace, 몸통용 Trace
- 각 `WeaponTrace`에 `Shape` 추가
    - 타입: `Sphere / Capsule / Box`
    - `Local Pos / Local Rot`로 위치/각도 맞추기
- **이동 판정(스윕)이 필요하면**
    - `Path Sweep Enabled` ON
    - `Path Start / Control / End` 설정
    - 현재 방식: **활성 구간 전체를 기준으로 `0 → 1` 보간**
- `debugDraw` ON 해서 모양/위치 바로 확인

---

## 2) AttackDriver에 Trace 슬롯 연결

**목표:** 공격 주체(보스/플레이어)가 “어떤 WeaponTrace들을 쓸지” 슬롯에 꽂아둔다.

- 공격 주체 엔티티에 `AttackDriverComponent` 추가
- 기본 슬롯
    - `Trace (pick entity)` = **Slot0 (Primary)**
- 추가 슬롯
    - `Additional Trace Slots`에서 Slot1, Slot2… 추가
    - 각 슬롯에 다른 `WeaponTrace` 엔티티 연결
- 예시 구성
    - `Slot0 = 무기`
    - `Slot1 = 발`
    - `Slot2 = 몸통`

---

## 3) 클립별 공격 윈도우(타이밍) 작성

**목표:** 애니메이션 클립의 “어느 시간대에 어떤 슬롯을 켤지”를 `Clip Timings`에 적는다.

- `Clip Timings`에 row 추가
- 보통 `Type = Attack`
- `Source / Clip` 선택
- `Start Time`, `End Time` 설정
- 슬롯 적용 방식
    - `Use All Trace Slots` ON → **모든 슬롯 동시 활성**
    - OFF → 필요한 슬롯만 체크 (`Slot0`, `Slot1`, … 멀티 선택)

---

## 4) 운영 규칙 (이거 모르면 헛짓하기 딱 좋음)

- 같은 클립에 row 여러 개 → **다단히트 타이밍 구성 가능**
- 같은 시간에 여러 슬롯 체크 → **여러 히트박스 동시 활성**
- 같은 슬롯의 활성 구간이 겹치면 → **연속 활성로 취급**
- **한 번의 활성 구간 동안 동일 대상은 1회만 히트**
- 다시 맞추고 싶으면?
    - **비활성 구간을 끼우도록** row를 분리해서 “꺼졌다 켜지는 구간”을 만들어야 함

---

## 5) 예시: `Attack_Kick` 2타 구성

- row1
    - `Clip = Attack_Kick`
    - `0.20 ~ 0.45`
    - `Slot1 (발 앞)` 체크
- row2
    - `Clip = Attack_Kick`
    - `0.55 ~ 0.85`
    - `Slot2 (발 옆)` 체크

→ 같은 킥 클립에서 **서로 다른 판정/타이밍으로 2번** 때릴 수 있음.

## 6) 저장/로드 (세팅 유지되는지)

- `traceSlotMask`는 **씬 저장/로드에 포함**
- 인스펙터에서 설정한 슬롯 마스크가 **직렬화되어 그대로 유지**
- 즉, 에디터에서 맞춘 값은 씬 재로드해도 안 날아감
