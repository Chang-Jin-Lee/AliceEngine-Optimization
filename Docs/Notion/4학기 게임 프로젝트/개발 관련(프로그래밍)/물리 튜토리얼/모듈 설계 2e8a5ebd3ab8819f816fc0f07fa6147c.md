---

기본적으로 ECS 구조를 최대한 살릴 생각

PhysXContext << 전역급 리소스 / 엔진의 시작과 끝에서 한번만 생성해서 관리함

PhysXWorld << 씬 단위로 사용함

- 씬마다 월드를 생성 파괴하는게 마음에 안들어요
    
    각 씬마다 누적된 데이터들을 격리하기 위해서 필요해요
    
    월드 하나로 처리하게 되면, 이전 씬에서 있었던 물리 내용을 전부 해제해줘야하는데
    
    힘든 작업이에요 터질 가능성도 높고
    
    가비지 컬렉터 기능을 가볍게 구현해야하는데, 차라리 생성 파괴하는쪽이 더 쉽다고 판단했어요
    
    마음에 안들면 쓰지 말든가 ㅗㅗ
    

PXScene에는 락 안걸고 접근하면 터짐

Engine Init / ~Engine에서 Context 초기화해주고, Shutdown 해줌

**씬 전환 시:** `OnExit → World::Clear(스크립트/핸들 파괴) → 물리월드 파괴 → 새 물리월드 생성 → OnEnter`

순서 지켜야함

---

구조

1. **엔진/게임 층 (ECS)**
- `RigidBodyComponent.h`, `ColliderComponent.h`, `TerrainHeightFieldComponent.h`
- `PhysicsSystem.cpp/h` : ECS 컴포넌트 ↔ PhysX월드 연결, 동기화/생성/파괴/이벤트 라우팅
1. **엔진용 물리 인터페이스 층(백엔드 추상화)**
- `IPhysicsWorld.h` : 엔진이 물리 백엔드를 “뭐든” 갈아끼울 수 있게 만든 API
1. **PhysX 5.5 백엔드 구현 층**
- `PhysicsModule.*` : Context(전역) + World(씬) 수명 관리
- `PhysXContext.*` : Foundation/Physics/Dispatcher/PVD/Cooking 세팅
- `PhysXWorld.*` + `PhysXWorld_Internal.h` : PxScene + Actor/Shape/Joint/Query/이벤트/캐시/락ㅊ

물리 관련된 추가하면 좋은 기능들

### 1) CCT Hit Report 이벤트 브릿지

소울라이크에서 플레이어가 벽/오브젝트/다른 캐릭터에 부딪힐 때:

- 발소리/스크래치 VFX
- “밀기” 상호작용
- 접촉 기반 반응(좁은 문틀, 난간 등)

이런 거 하려면 CCT 쪽 **`PxUserControllerHitReport`**를 받아서 ECS 이벤트로 올리는 게 되게 유용함. PhysX 문서도 캐릭터가 shape에 부딪힐 때 `onShapeHit()` 콜백을 준다고 딱 말함.

지금 래퍼는 “Move + state 조회”는 좋은데, **CCT 히트 이벤트를 게임으로 올리는 라인이 없음**.

### 2) 기본 최대 각속도(7 rad/s) 방치 문제

PhysX 쪽 기본 최대 각속도가 낮아서 “물체가 이상하게 안 돈다” 문제가 흔함. Best Practices에도 기본이 낮다고 찍어서 말해.

지금 `RigidBodyDesc.maxAngularVelocity == 0`이면 기본값을 쓰는데, 소울라이크에서 항아리/시체/무기 같은 거 던지면 **스핀감이 멍청하게 제한**될 수 있음.

### CCT 엔티티 구성 규칙

- **Transform + CharacterControllerComponent만** 둬라.
- RigidBody/Collider를 같은 엔티티에 같이 두면:
    
    “RB이동/teleport 로직 vs CCT Move”가 **서로 Transform을 빼앗아감** 
    

소울라이크에서 흔한 패턴:

- 플레이어 본체: CCT
- 무기 히트박스/트리거: 자식 엔티티에 Trigger Collider
- 피격 판정(허트박스): 별도 콜라이더(대개 trigger)

- 릴리즈 흐름(헷갈리면 볼려고 씀)
    
    ## 씬 전환 시 Destroy/Release 흐름 정리
    
    ### 1. 씬 전환 트리거 지점
    
    ```cpp
    // src/Core/Scene.cpp
    SceneManager::SwitchTo()
      → m_currentScene->OnExit()  // 이전 씬 종료
      → World::Clear() 호출 (씬 파일 로드 시)
    
    ```
    
    ### 2. World::Clear() 호출 체인
    
    ```
    World::Clear()
      ↓
      [0단계] OnBeforeClear 콜백 실행
        ↓
        Engine::SetOnBeforeClearCallback()에서 설정된 람다
          ↓
          1. PhysXWorld::Flush()  // pending 작업 처리
          2. PhysicsSystem::SetPhysicsWorld(nullptr)  // ⭐ 핵심
    
    ```
    
    ### 3. PhysicsSystem::SetPhysicsWorld(nullptr) - 핵심 정리 단계
    
    ```cpp
    // src/PhysX/PhysicsSystem.cpp:118-159
    
    PhysicsSystem::SetPhysicsWorld(nullptr)
      ↓
      [1단계] Flush (이전 씬의 pending 작업 처리)
        → m_physicsWorld->Flush()
          → PhysXWorld::Flush()
            → Impl::FlushPending(true)
              → pendingRelease의 모든 PxBase*에 대해 release() 호출
              → pendingControllerRelease의 모든 PxController*에 대해 release() 호출
      ↓
      [2단계] 모든 Actor 정리
        → for each entityId in m_entityToActor:
            → DestroyPhysicsActor(entityId)
              → 컴포넌트의 physicsActorHandle = nullptr
              → ActorHandle::Destroy() 호출
                → IPhysicsActor::Destroy()
                  → PhysXActor::Destroy() 또는 PhysXRigidBody::Destroy()
                    → EnqueueRemove(actor)  // scene에서 제거 예약
                    → EnqueueRelease(actor)  // release 예약
        → m_entityToActor.clear()
        → m_lastTransforms.clear()
        → m_lastColliders.clear()
        → m_lastRigidBodies.clear()
        → m_lastTerrains.clear()
      ↓
      [3단계] 모든 CCT 정리
        → for each entityId in m_entityToCCT:
            → CCTHandle::Destroy()
              → ICharacterController::Destroy()
                → PhysXCharacterController::Destroy()
                  → EnqueueControllerRelease(controller)
        → m_entityToCCT.clear()
        → m_lastCCTs.clear()
      ↓
      [4단계] 최종 Flush
        → m_physicsWorld->Flush()  // 위에서 예약된 release 처리
      ↓
      [5단계] 포인터 해제
        → m_physicsWorld = nullptr
    
    ```
    
    ### 4. DestroyPhysicsActor() 상세 흐름
    
    ```cpp
    // src/PhysX/PhysicsSystem.cpp:1380-1425
    
    DestroyPhysicsActor(entityId)
      ↓
      1. 컴포넌트 핸들 null 처리
        → RigidBodyComponent::physicsActorHandle = nullptr
        → ColliderComponent::physicsActorHandle = nullptr
        → TerrainHeightFieldComponent::physicsActorHandle = nullptr
      ↓
      2. ActorHandle::Destroy() 호출 (조건부)
        if (m_physicsWorld != nullptr && handle.owned):
          → handle.Destroy()
            → owned->Destroy()  // IPhysicsActor::Destroy()
              → PhysXActor::Destroy() 또는 PhysXRigidBody::Destroy()
                → EnqueueRemove(actor)  // scene에서 제거
                → EnqueueRelease(actor)  // release 예약
            → owned.reset()  // unique_ptr 해제
        else:
          → handle.owned.reset()  // 직접 해제만
      ↓
      3. 맵에서 제거
        → m_entityToActor.erase(it)
        → m_lastTransforms.erase(entityId)
        → m_lastColliders.erase(entityId)
        → m_lastRigidBodies.erase(entityId)
        → m_lastTerrains.erase(entityId)
    
    ```
    
    ### 5. PhysXActor::Destroy() → EnqueueRelease 흐름
    
    ```cpp
    // src/PhysX/PhysXWorld_Internal.h:1575-1589
    
    PhysXActor::Destroy()
      ↓
      1. world.lock()으로 Impl 가져오기
        → auto s = world.lock()
      ↓
      2. Scene에서 제거 예약
        → s->EnqueueRemove(actor)
          → pendingActorOps에 Remove 작업 추가
      ↓
      3. Release 예약
        → s->EnqueueRelease(actor)
          → pendingRelease에 PxActor* 추가
    
    ```
    
    ### 6. FlushPending() - 실제 Release 실행
    
    ```cpp
    // src/PhysX/PhysXWorld_Internal.h:886-980
    
    FlushPending(allowImmediateRelease=true)
      ↓
      [1단계] Pending 작업 수집
        → pendingActorOps.swap()  // Add/Remove 작업
        → pendingRelease.swap()   // Release할 객체들
        → pendingControllerRelease.swap()  // Release할 CCT들
      ↓
      [2단계] Scene에 Actor 추가/제거
        → for each ActorOp:
            if (Add): scene->addActor(*a)
            if (Remove): scene->removeActor(*a)
      ↓
      [3단계] 중복 제거 (중요!)
        → std::sort(rels.begin(), rels.end())
        → std::unique()  // 같은 포인터가 여러 번 release되는 것 방지
      ↓
      [4단계] Actor Release
        → for each PxBase* in rels:
            1. Scene에 있으면 먼저 제거
               → if (a->getScene() == scene): scene->removeActor(*a)
            2. Release 호출
               → b->release()  // ⭐ 실제 PhysX 객체 해제
      ↓
      [5단계] Controller Release (마지막)
        → for each PxController* in ctrls:
            → c->release()  // CCT는 내부에 kinematic actor를 가지므로 마지막에 해제
    
    ```
    
    ### 7. World::Clear() - 최종 정리
    
    ```cpp
    // src/Core/World.cpp:6-42
    
    World::Clear()
      ↓
      [0단계] OnBeforeClear 콜백 (위에서 처리됨)
      ↓
      [1단계] 스크립트 정리
        → RemoveAllScript()
      ↓
      [2단계] 물리 월드 해제
        → m_physicsWorld.reset()  // shared_ptr 해제
          → PhysXWorld::~PhysXWorld()
            → Impl::~Impl()
              → FlushPending(true)  // 마지막 pending 처리
              → defaultMaterial->release()
              → controllerMgr->release()  // CCT Manager 해제
              → scene->release()  // ⭐ PxScene 해제
              → ClearMeshCachesInternal()  // 캐시된 메시/재질 해제
      ↓
      [3단계] 컴포넌트 저장소 클리어
        → storage->Clear()  // 모든 컴포넌트 제거
      ↓
      [4단계] World Epoch 증가
        → ++m_worldEpoch  // 이전 씬의 userData 무효화
    
    ```
    
    ### 8. 전체 흐름 다이어그램
    
    ```
    씬 전환 요청
        ↓
    SceneManager::SwitchTo()
        ↓
    World::Clear()
        ↓
    [OnBeforeClear 콜백]
        ↓
    PhysXWorld::Flush()  ──→ FlushPending(true) ──→ 모든 pending release 실행
        ↓
    PhysicsSystem::SetPhysicsWorld(nullptr)
        ↓
    ┌─────────────────────────────────────┐
    │ 1. 모든 Actor Destroy               │
    │    → DestroyPhysicsActor()          │
    │      → ActorHandle::Destroy()       │
    │        → EnqueueRelease()           │
    │                                     │
    │ 2. 모든 CCT Destroy                 │
    │    → CCTHandle::Destroy()           │
    │      → EnqueueControllerRelease()   │
    │                                     │
    │ 3. Flush (예약된 release 실행)      │
    │    → FlushPending(true)             │
    │      → scene->removeActor()         │
    │      → actor->release() ⭐          │
    │      → controller->release() ⭐     │
    └─────────────────────────────────────┘
        ↓
    m_physicsWorld = nullptr
        ↓
    World::Clear() 계속
        ↓
    m_physicsWorld.reset()  ──→ PhysXWorld 소멸
        ↓
    Impl::~Impl()
        ↓
    ┌─────────────────────────────────────┐
    │ 최종 정리:                          │
    │ → FlushPending(true)                │
    │ → defaultMaterial->release()        │
    │ → controllerMgr->release()          │
    │ → scene->release() ⭐               │
    │ → ClearMeshCachesInternal()         │
    └─────────────────────────────────────┘
    
    ```
    
    ### 주요 Release 호출 지점 요약
    
    1. FlushPending() 내부
        - `b->release()` - 모든 PxBase* (Actor, Shape, Joint 등)
        - `c->release()` - 모든 PxController*
    2. Impl::~Impl() 소멸자
        - `defaultMaterial->release()`
        - `controllerMgr->release()`
        - `scene->release()` - PxScene 자체
        - 캐시된 메시/재질 release
    3. 안전장치
        - 중복 release 방지: `std::unique()`로 중복 제거
        - Scene에서 먼저 제거 후 release
        - Controller는 마지막에 release (내부 kinematic actor 때문)
    
    이 흐름으로 씬 전환 시 물리 객체가 안전하게 정리됩니다.
