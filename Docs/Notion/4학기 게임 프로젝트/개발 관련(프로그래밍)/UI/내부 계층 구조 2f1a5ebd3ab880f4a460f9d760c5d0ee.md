# 내부 계층 구조

**UIWorldManager** 
│   
├─ sceneStorages: map<string, UISceneManager*>
│   │
│   └─ **UISceneManager** (N개, 씬별)
│       │
│       └─ m_world: **UIWorld** (1개)
│           │
│           ├─ pUIObjStorage: map<ID, UIBase*>
│           │   │
│           │   └─ **UIBase** (N개, 트리 구조)
│           │       │
│           │       ├─ parentID → 다른 UIBase
│           │       ├─ childIDStorage → 다른 UIBase들
│           │       │
│           │       └─ 컴포넌트 접근 (델리게이트)
│           │           │
│           │           └─ **IUIComponent** (N개)
│           │               │ 
│           │               └─ Owner → UIBase
│           │
│           └─ 컴포넌트 저장소 (월드 소유)
│               ├─ m_transformStorage: map<OwnerID, UITransform*>
│               ├─ m_imageComponentStorage: map<OwnerID, UI_ImageComponent*>
│               └─ m_scriptComponentStorage: map<OwnerID, UI_ScriptComponent*>

### UIWorldManager (최상위 매니저)

역할: 전역 UI 관리, 렌더링 리소스, 씬 관리                      

📦 구조

│

├─ 🎨 렌더링 리소스 (D3D11 + D2D)

│   ├─ m_tex2D, m_shaderRV, m_RenderTV, m_pAlphaBlendState

│   ├─ m_d2DFactory, m_d2DDevice, m_d2DdevCon, m_d2dTargetBitmap

│   └─ m_D3DWFactory, m_wicFactory, m_brush

│

├─ 📁 씬 관리

│   ├─ sceneStorages: map<씬이름, UISceneManager*>  ← SceneManager을 소유함

│   ├─ m_nowSceneName: 현재 씬 이름

│   └─ m_nowManager: 현재 활성 씬 매니저 포인터

│

└─ 🔧 주요 기능

├─ Initialize(): 렌더링 리소스 초기화

├─ Update(): 현재 씬 업데이트 위임

├─ Render(): 현재 씬 렌더링 위임

├─ ChangeScene(): 씬 전환 (매니저 선택/생성)

├─ LoadUI(): UI 씬 파일 로드

└─ SaveUI(): UI 씬 파일 저장

관계: UIWorldManager 1개 → UISceneManager 여러 개 (씬별)

### UISceneManager (씬별 UI 관리)

역할: 씬 단위 UI 월드 관리, 시스템 업데이트/렌더링              

📦 구조

│

├─ 🔧 디바이스/리소스 참조

│   ├─ pDev: ID3D11Device*

│   ├─ pDevCon: ID3D11DeviceContext*

│   ├─ m_InputSystem: InputSystem*

│   └─ m_UIRenderStruct: UIRenderStruct*

│

├─ 📦 UIWorld 인스턴스

│   └─ m_world: UIWorld  ← 월드를 소유함!!!

│

└─ 🔧 주요 기능

├─ Initialize(): 디바이스/리소스 설정, UIWorld 초기화

├─ Update(): 시스템 업데이트 (Layout, Script, Image, Input, Event)

├─ Render(): 렌더링 시스템 호출

│

└─ UIWorld 래퍼 메서드 (템플릿)

├─ CreateUIObjects<T>(): 엔티티 생성

├─ CreateChildUIObjects<T>(): 자식 엔티티 생성

├─ Get(ID): 엔티티 조회

├─ CreateComponent<T>(): 컴포넌트 생성

└─ TryGetComponent<T>(): 컴포넌트 조회

관계: UISceneManager 1개 → UIWorld 1개

### UIWorld

엔티티/컴포넌트 저장소, 생명주기 관리                     

📦 구조

│

├─ 🗂️ 엔티티 저장소

│   ├─ pUIObjStorage: map<ID, unique_ptr<UIBase>>  ←UIBase를 상속하는 object들 관리

│   └─ m_rootID: vector<ID> (루트 노드 ID 목록)

│

├─ 🧩 컴포넌트 저장소 (월드 소유)

│   ├─ m_transformStorage: map<OwnerID, unique_ptr<UITransform>>

│   ├─ m_imageComponentStorage: map<OwnerID, unique_ptr<UI_ImageComponent>>

│   └─ m_scriptComponentStorage: map<OwnerID, unique_ptr<UI_ScriptComponent>>

│

├─ 🔗 델리게이트 시스템

│   └─ m_worldDelegates: CompDelegates (컴포넌트 생성/조회/삭제)

│

└─ 🔧 주요 기능

├─ Initialize(): 델리게이트 바인딩

│

├─ 엔티티 관리

│   ├─ CreateEntity<T>(): 엔티티 생성 (루트로 추가)

│   ├─ CreateChildEntity<T>(): 자식 엔티티 생성

│   ├─ Get(ID): 엔티티 조회

│   ├─ DestroyEntity(ID): 엔티티 삭제 (자식 포함)

│   └─ SetParent(): 부모-자식 관계 설정

│

├─ 컴포넌트 관리 (고정 타입)

│   ├─ CreateTransformComponent(OwnerID)

│   ├─ CreateImageComponent(OwnerID)

│   ├─ CreateScriptComponent(OwnerID)

│   └─ Find/Remove 메서드들

│

└─ 컴포넌트 관리 (템플릿/델리게이트)

├─ CreateComponent<T>(OwnerID): 델리게이트로 생성

├─ TryGetComponent<T>(OwnerID): 델리게이트로 조회

└─ RemoveComponent<T>(OwnerID): 델리게이트로 삭제

관계: UIWorld 1개 → UIBase 여러 개 (트리 구조)

### UIBase (UI 엔티티 기본 클래스)

역할: UI 객체 기본 기능, 컴포넌트 접근, 트리 구조               

📦 구조

│

├─ 🆔 식별자

│   ├─ ID: long unsigned (엔티티 ID)

│   ├─ parentID: long unsigned (부모 ID)

│   └─ childIDStorage: vector<ID> (자식 ID 목록)

│

├─ 🎯 Transform 캐시

│   └─ Transform: UITransform* (캐시된 포인터)

│

├─ 🔗 델리게이트 참조

│   └─ m_world: CompDelegates* (컴포넌트 접근용)

│

├─ 🎨 렌더링

│   └─ m_UIRenderStruct: UIRenderStruct* (렌더 구조체)

│

└─ 🔧 주요 기능

├─ 가상 함수 (파생 클래스 구현)

│   ├─ Initialize(): 초기화

│   ├─ Update(): 업데이트 (순수 가상)

│   └─ Render(): 렌더링 (순수 가상)

│

├─ 컴포넌트 헬퍼 (템플릿)

│   ├─ AddComponent<T>(args...): 컴포넌트 추가

│   ├─ TryGetComponent<T>(): 컴포넌트 조회

│   ├─ GetComponent<T>(): 컴포넌트 조회 (assert)

│   └─ RemoveComponent<T>(): 컴포넌트 제거

│

└─ 트리 구조 접근자

├─ getID(): ID 반환

├─ GetParentID(): 부모 ID 반환

└─ GetChildIDs(): 자식 ID 목록 반환

관계: UIBase ID가 → IUIComponent를 종류별로 하나씩 사용 할 수 있음  

### UIComponent (컴포넌트 기본 인터페이스)

역할: 컴포넌트 공통 인터페이스, 소유자 참조                     

📦 구조

│

├─ 👤 소유자 참조

│   ├─ Owner: UIBase* (소유 엔티티 포인터)

│   └─ OwnerID: unsigned long (소유 엔티티 ID) → 이걸 키로 컴포넌트 저장함

│

├─ 🆔 식별자 (레거시)

│   ├─ id: long unsigned

│   └─ owner: long unsigned

│

└─ 🔧 가상 함수

└─ OnAdded(): 컴포넌트 추가 시 호출 (기본 빈 구현)

**파생 컴포넌트:**

├─ UITransform: 변환 (위치, 회전, 스케일)

├─ UI_ImageComponent: 이미지 렌더링

├─ UI_InputComponent: 입력 처리

└─ UI_ScriptComponent: 스크립트 실행

관계: IUIComponent 여러 개 → UIBase 1개 (N:1)

**생성 흐름:**

1. UIWorldManager::LoadUI()

→ UISceneManager 생성/선택

→ UIWorld::CreateEntity<T>()

→ UIBase 생성 및 Initialize()

→ UIBase::AddComponent<T>() → UIWorld::CreateComponent<T>() (델리게이트)  → 컴포넌트 저장소에 저장

**조회 흐름:**

1. UIBase::TryGetComponent<T>()

→ m_world->FindComponent.Execute()

→ UIWorld::TryGetComponent<T>()

→ 컴포넌트 저장소에서 조회

**업데이트 흐름:**

1. UIWorldManager::Update()

→ UISceneManager::Update()

→ 각 시스템 업데이트 (Layout, Script, Image, Input, Event)

→ UIBase::Update() (각 엔티티)

→ 컴포넌트 업데이트
