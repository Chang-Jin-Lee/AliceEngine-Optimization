# 서브모듈

서브 모듈

- 서브모듈 받을 때 init 으로 초기화하기

```cpp
git submodule update --init ThirdParty/ImGui
```

- 서브모듈 추가

```cpp
git submodule add https://github.com/Chang-Jin-Lee/imgui.git ThirdParty/ImGui
```

- 서브모듈 측정 브랜치로 추가

```cpp
git submodule add -b docking https://github.com/Chang-Jin-Lee/imgui.git ThirdParty/ImGui
```

- 서브모듈 특정 브랜치로 checkout하기

```cpp
cd ThirdParty/ImGui
git fetch origin
git checkout <branch_name>                                     # 예: docking
# 또는 새 브랜치 생성: git checkout -b <branch> origin/<branch>

# 메인 repo에서 변경 커밋
git add ThirdParty/ImGui
git commit -m "Switch ImGui to docking branch"
```

- 서브모듈 갱신

```cpp
git submodule update --remote ThirdParty/ImGui 
```

- 서브모듈 전부 갱신

```cpp
git submodule update --init --recursive
```

- 서브모듈 제거

```cpp
git submodule deinit -f ThirdParty/ImGui
git rm -f ThirdParty/ImGui

rm -rf .git/modules/ThirdParty/ImGui
rm -rf ThirdParty/ImGui
```
