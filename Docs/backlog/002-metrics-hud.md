# 002 — 계측 오버레이

001에서 모은 값을 화면에 띄웁니다. 영상에서 게임이 가려지면 안 되므로 작고 읽히게 만드는 것이 조건입니다.

## 선행 조건

001의 완료 조건을 모두 통과한 상태여야 합니다.

## 새로 만들 파일

```
EngineSource/Engine/src/Editor/Panels/MetricsOverlay.cpp
EngineSource/Engine/src/Editor/Panels/MetricsOverlay.h
```

기존 패널(`Editor/Panels/CameraPanel.cpp`, `LightingPanel.cpp`)의 등록 방식과 ImGui 사용 관례를 먼저 읽고 같은 형태로 맞추십시오.
에디터 모드가 아닌 게임 실행에서도 떠야 하므로, `m_editorMode` 분기 안쪽이 아니라 `RenderGameModeToneMappingAndUI` 이후에 그리도록 배치합니다.

## 레이아웃

우상단 고정, 폭 340px, 배경 알파 0.55, `ImGuiWindowFlags_NoMove | NoResize | NoCollapse | NoTitleBar | AlwaysAutoResize`.
게임 화면을 가리는 면적이 전체의 15%를 넘지 않아야 합니다.

내용은 위에서 아래로 이 순서입니다.

**첫 줄은 크게.** `frame 8.24 ms  (121 fps)` — 폰트 스케일 1.6배. 영상에서 이 한 줄이 가장 먼저 읽혀야 합니다.

**둘째 줄.** `CPU 3.10 ms   GPU 7.92 ms` — CPU와 GPU를 나란히. 이 두 값이 다르다는 것 자체가 계측을 이해하고 있다는 표시입니다.

**프레임타임 그래프.** `ImGui::PlotLines`로 최근 240프레임. 높이 60px, y축 상한은 고정값(예: 40ms)으로 두십시오. 자동 스케일이면 토글 순간에 축이 같이 움직여서 개선이 눈에 안 보입니다. **영상에서 가장 잘 읽히는 요소이므로 여기를 소홀히 하지 마십시오.**

**통계 요약.** 측정 창 안의 `min / avg / max / 1% low`. 평균만 있으면 "그 순간만 좋았던 것 아니냐"는 질문을 못 막습니다. 1% low는 프레임타임 상위 1%의 평균으로 계산합니다.

**패스별 GPU 표.** `ImGui::BeginTable` 2열로 스코프 이름과 ms. 값이 큰 순서로 정렬하지 말고 렌더 순서대로 두십시오. 순서가 고정되어야 두 영상을 비교할 수 있습니다.

**카운터.** 드로우콜, 인스턴스드 드로우콜, IAPrimitives, PSInvocations, 본 CB Map 횟수와 업로드 MB.

**메모리.** VRAM 사용/예산 MB, 워킹셋 MB.

**상태 배지.** 지금 legacy 토글이 켜져 있는지(003에서 추가), vsync 상태, 해상도. 영상 자막을 따로 안 넣어도 화면에 조건이 남습니다.

## 표시 규칙

- ms는 소수점 둘째 자리까지, MB는 정수. 자릿수가 흔들리면 영상에서 숫자가 덜컹거립니다.
- `Disjoint`로 폐기된 프레임은 직전 값을 유지하고 그래프에도 직전 값을 넣습니다. 0을 넣으면 그래프가 바닥을 칩니다.
- 폐기 누적 횟수를 작게 표시하십시오. 폐기가 많으면 측정을 신뢰할 수 없다는 신호입니다.
- 색은 기본 ImGui 색만 씁니다. 임계값에 따라 빨강·초록으로 바꾸지 마십시오. 영상에서 값이 아니라 색을 보게 됩니다.

## 토글 키

`F9`로 오버레이를 켜고 끕니다. `Runtime/Input`의 기존 입력 경로를 쓰고 하드코딩된 `GetAsyncKeyState`를 새로 넣지 마십시오.

## 완료 조건

1. `Build.bat`이 성공합니다.
2. 에디터와 게임 실행 양쪽에서 오버레이가 뜨고 `F9`로 토글됩니다.
3. 1920×1080에서 오버레이가 차지하는 면적이 화면의 15% 이하입니다. 스크린샷을 하나 남겨 확인하십시오.
4. 프레임타임 그래프가 240프레임을 채우고, 씬을 무겁게 만들면(카메라를 타일 밀집 구역으로 옮기면) 선이 올라갑니다.
5. 오버레이를 켠 상태와 끈 상태의 평균 `presentMs` 차이가 3% 이내입니다.
6. 스크린샷 한 장을 `Docs/backlog/assets/002-overlay.png`로 저장하고 **직접 열어서** 숫자가 읽히는지 확인하십시오. 흐릿하거나 잘렸으면 폭과 폰트 스케일을 조정하고 다시 찍습니다.

## 실패 시

숫자가 안 읽히거나 게임이 가려지면 커밋하지 말고 스크린샷과 함께 보고하십시오.
