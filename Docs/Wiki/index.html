EGOSIS 엔진 위키

EGOSIS는 C++ · DirectX 11 · HLSL로 만든 3D 액션게임용 자체 엔진입니다. 내부 렌더러 이름은 AliceRenderer이며, ImGui 기반 에디터와 ECS 런타임을 함께 갖추고 있습니다.

이 위키는 엔진의 구조와 사용법을 모듈별로 정리한 백과사전입니다. 왼쪽 메뉴에서 원하는 주제를 고르거나 검색창으로 찾으세요.

한눈에 보는 기술 스택

C++20DirectX 11HLSL ECS (Sparse Set)NVIDIA PhysX ImGui 에디터RTTR 리플렉션 스크립트 DLL 핫리로드CMake + vcpkg

주요 모듈 빠른 안내

ECS

World·Entity·Component. Sparse Set 기반 저장소.

Rendering

Forward / Deferred 두 경로, 아웃라인·포스트프로세스.

Physics

PhysX 연동. 리지드바디·콜라이더·캐릭터 컨트롤러.

Scripting

Unity 스타일 라이프사이클. DLL 핫리로드.

Gameplay

애니메이션 블루프린트, 루트모션, 전투, 소켓.

Editor

ImGui 패널 · 인스펙터 · 노드 블루프린트.
