데칼 사용법

데칼은 "붙이는" 게 아니라 큐브 볼륨으로 "쏘는" 프로젝터입니다. Deferred 경로에서 DBuffer로 합성합니다.

파이프라인

flowchart LR
  A["GBuffer Pass"] --> B["Decal Pass
DBuffer 클리어 → 박스 렌더
Depth로 월드 복원 → 범위 밖 discard"]
  B --> C["Light Pass 합성
base*(1-a) + decalColor"]

Quick Start

  1. 빈 엔티티 생성 → DecalComponent 추가
  2. Albedo Texture에 이미지 연결(알파 = 마스크)
  3. Transform으로 데칼 박스를 벽/바닥에 겹치게 배치 — 박스의 Look 방향이 투영 방향

속성: Enabled / Texture / Color(틴트) / Opacity / Sort Order / UV Scale·Offset. View 메뉴의 "Decal DBuffer"로 디버그할 수 있습니다.

알베도 전용(Normal/RMA 미지원)이며 Forward 경로에서는 미지원입니다. 데모 씬: Assets/Scenes/Decal/DecalDemo.scene
