에디터 구조

ImGui 기반 도킹 에디터입니다. EditorCore가 모든 창을 순서대로 그리며 런타임 World를 직접 편집합니다.

구성

flowchart TB
  Core["EditorCore
DrawEditorUI() 오케스트레이터"]
  State["EditorUIState
전역 상태(씬 dirty, 경로)"]
  Undo["EditorUndoRedo
커맨드 스택"]
  Core --> State
  Core --> Undo
  subgraph Panels["Panels"]
    H["Hierarchy"]; I["Inspector"]; P["Project"]; V["GameViewport"]
    C["Camera"]; L["Lighting"]
  end
  subgraph Tools["Tools / AssetEditors"]
    BP["AnimBlueprintEditor (노드)"]
    MAT["MaterialAssetEditor"]
    PRE["PreloadAssetEditor"]
  end
  Core --> Panels
  Core --> Tools
  Panels --> World["런타임 World"]

주요 패널

패널기능
Hierarchy엔티티 트리, 드래그&드롭, Rename/Delete
Inspector선택 엔티티의 컴포넌트 편집(타입별 드로어)
Project에셋 디렉터리 트리, 더블클릭 시 전용 에디터
GameViewport뷰포트 + 기즈모 + 픽킹 + 에디터 프리캠
Lighting조명·스카이박스 (포스트프로세스는 PPV에서)

인스펙터 드로어

컴포넌트 종류별로 분리되어 있습니다: Transform, Scripting, Rendering(Material/Light), Physics(RigidBody/Collider), Camera, Combat, Socket. RTTR 리플렉션 UI로 자동 생성되는 부분도 있습니다.

에디터는 별도 레이어가 아니라 런타임 타입(World, Component, RenderSystem)을 직접 포함해 편집합니다.

관련 파일: Editor/Core/*, Editor/Panels/*, Editor/Inspector/*, Editor/Tools/Blueprint/*
