# 플레이어 파라미터 리스트 업

| 스태미나 및 체력 |  |  |
| --- | --- | --- |
| 변수명 (Variable Name) | 추천 초기값 | 설명 및 UX 의도 |
| Max HP | 100 | 기준점. 보스 공격력을 이 수치에 맞춰 설계 (예: 약공격 15, 강공격 40). |
| Max Weapon Hp | 100 | 동일한 기준점. |
| Max Stamina | 100 | 모든 행동의 자원. |
| Stamina Regen Rate | 15 / sec | 초당 회복량. 가드를 내리고 있을 때만 회복. |
| Stamina Regen Delay | 1.5 (sec) | (중요) 공격/회피 후 바로 회복되면 안 됨. 행동 종료 후 1.5초 뒤부터 회복 시작. |
| Guard Weapon HP rate | 100% | 가드 중 무기 hp가 받는 데미지 비율(100%면 플레이어랑 동일한 데미지 수치를 받음) |
|  |  |  |
| 스태미나 및 자원 |  |  |
| 변수명 (Variable Name) | 추천 초기값 | 설명 및 UX 의도 |
| Light Atk Damage | 10 | 짤짤이 데미지. 보스 HP가 1000이라면 100대 때려야 함. |
| Heavy Atk Damage | 25 | 큰 기술. 리스크 대비 보상이 확실해야 함. |
| Guard Damage Cut | 100 (%) | 물리 데미지 경감률. 100%면 데미지 0. (단, 스테미나 깎임) |
| Perfect Guard Window | 0.5 (sec) | 핵심 변수. 가드 입력 후 0.5초 내 피격 시 패링 인정. (어려우면 0.7로 완화) |
| Stamina Cost (Light) | 10 | 약공격 소모량. 10번 연속 휘두를 수 있음. |
| Stamina Cost (Heavy) | 25 | 강공격 소모량. |
| Stamina Cost (Dodge) | 15 | 구르기 소모량. 남발 방지. |
| 연출 감각 |  |  |
| 변수명 (Variable Name) | 추천 초기값 | 설명 및 UX 의도 |
| Hit Stop (Light) | 0.1 (sec) | 때렸을 때 순간 정지 시간. 타격감의 기본. |
| Hit Stop (Heavy) | 0.2 (sec) | 강공격이나 막타 성공 시 더 길게 멈춤. |
| Parry Time Scale | 0.1 | 패링 성공 시 시간 왜곡. 순간적으로 게임 속도가 0.1배속으로 느려짐. |
| Parry Slow Duration | 0.5 (sec) | 위 슬로우 효과가 지속되는 시간. (극적 연출) |
| Camera Shake (Hit) | 0.2 | 피격 시 카메라 흔들림 강도. |
| Camera Shake (Heavy) | 0.5 | 보스 내려찍기 등 강한 충격 시 흔들림 강도. |
