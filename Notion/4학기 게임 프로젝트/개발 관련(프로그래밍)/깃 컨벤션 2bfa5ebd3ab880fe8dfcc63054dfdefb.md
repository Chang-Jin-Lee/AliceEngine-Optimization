# 깃 컨벤션

> 참고
> 

- feat, fix, refactor, chore를 위주로 쓰긴함. 나머지는 헷갈릴 때 들어와서 한번 보면 됩니다.
- 엄격하게 무조건 지켜야하는 것이 아닙니다. 팀끼리 어떤 작업을 했는지 보기 위함이니 여러 업무를 동시에 진행했으면 제일 많이 한 작업을 헤더로 적으시면 됩니다.
- 정 모르겠으면 밑 표를 Ai 한테 던져주고 지금 한 일을 설명하고 예시대로 적어줘 라고 하세요.

```cpp
[feat] update player controller to move character
```

| Header | 설명 |
| --- | --- |
| [feat] | 새로운 기능 추가 |
| [fix] | 버그 수정 |
| [docs] | README나 WIKI 등 문서 개정 |
| [design] | UI 레이아웃 조정 |
| [refactor] | 리팩토링(똑같이 동작하지만 코드 구조 변경) |
| [setting] | 프로젝트 기초 셋팅 |
| [chore] | 잡일 |
| [test] | 테스트 코드 수정 |
| [perf] | 최적화 |
