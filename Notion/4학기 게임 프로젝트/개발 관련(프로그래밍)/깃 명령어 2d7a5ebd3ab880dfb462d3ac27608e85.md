# 깃 명령어

병합 방법은 두개가 있음

1. 스태쉬 쓰기

→ 일단 지금까지의 작업을 스태쉬로 옮기고, 받아온 후 나중에 처리함
(병합을 위해 지금까지의 작업을 커밋 안해도 됨) + (받은 코드가 정상 작동하는지 먼저 볼 수 있음)
(병합을 실수했을 때 귀찮아짐)

1. 스태쉬 안쓰기

→ 지금까지 했던 작업을 커밋을 올려야합니다 (대신 실수했을때 대처하기는 더 편한듯?)

---

복붙해서 확장자를 정리해요!(컴퓨터에 깔린 모든거 해주는거에요)
→ 윈도우 누르고 파워쉘 켜서 아래있는거 복붙하면 됩니다(엔터 두번)

→ 모든 파일을 utf8 with Bom 으로 바꿔줍니다

- 누르면 커져요!
    
    ```csharp
    # 1. 대상 확장자 설정
    $extensions = @("*.h", "*.cpp", "*.hpp", "*.c", "*.inl")
    
    # 2. 인코딩 객체 생성
    $EncCP949 = [System.Text.Encoding]::GetEncoding(949) # 한국어 (EUC-KR)
    $EncUTF8 = [System.Text.Encoding]::UTF8              # UTF-8 (with BOM)
    
    # 3. 파일 순회 및 변환
    Get-ChildItem -Include $extensions -Recurse | ForEach-Object {
        $filePath = $_.FullName
        
        # 파일 내용을 바이트로 읽어서 BOM 확인
        $bytes = [System.IO.File]::ReadAllBytes($filePath)
        $isUTF8BOM = ($bytes.Length -ge 3) -and ($bytes[0] -eq 0xEF) -and ($bytes[1] -eq 0xBB) -and ($bytes[2] -eq 0xBF)
    
        if ($isUTF8BOM) {
            Write-Host "Skipping (Already UTF-8): $filePath" -ForegroundColor Gray
        }
        else {
            # BOM이 없으면 CP949(한글)로 간주하고 읽음
            $content = [System.IO.File]::ReadAllText($filePath, $EncCP949)
            
            # 내용을 UTF-8(BOM)로 덮어쓰기
            [System.IO.File]::WriteAllText($filePath, $content, $EncUTF8)
            
            Write-Host "Converted to UTF-8: $filePath" -ForegroundColor Green
        }
    }
    ```

## 다른 사람의 포크의 특정 브랜치에서 내 레포의 브랜치로 코드 가져오기

- 일단 원하는 레포의 경로를 원하는 이름으로 remote add를 해줌. nayuta 라고 할겁니다.

```cpp
 git remote add nayuta https://github.com/Cosmic-Disaster/AliceRenderer
```

- 그 다음 nayuta를 fetch 합니다

```cpp
 git fetch nayuta
```

- 그 다음 nayuta의 dev 브랜치를 pull 합니다

```cpp
git pull nayuta dev
```

```python
# 현재 설정된 주소 확인
git remote -v

# 새로운 주소로 변경 (예시)
git remote set-url origin https://github.com/사용자명/새로운-레포-이름.git
```

## **브랜치 관리**

```cpp
text# 현재 브랜치 확인
git branch

# 모든 브랜치 확인 (로컬+원격)
git branch -a

# 현재 모든 브런치의 커밋상태를 보는거(맞을껄요?)
git branch -vv 

# 현재 브랜치 상태
git status

# 브랜치 생성+이동
git checkout -b new-branch(이름임)

# 브랜치 만들고 리모트(원격 - 다른곳에서 쓰기)에 올리기
git switch -c 이름
git push -u origin 이름

# 브랜치 이동
git checkout branch-name
git switch branch-name

# 브랜치 삭제
git branch -d branch-name      # 안전삭제
git branch -D branch-name      # 강제삭제
```

## **변경사항 저장/복구**

```cpp
text# 변경사항 임시저장 (stash)
git stash push -m "메시지"
git stash list                  # stash 목록
git stash pop                   # 최신 stash 복구
git stash pop stash@{0}         # 특정 stash 복구
git stash drop stash@{0}        # stash 삭제

# 변경사항 무시하고 체크아웃
git checkout -f branch-name
git checkout branch-name -- .

# 특정 파일만 덮어쓰기
git checkout branch-name -- file.txt

# 변경 사항을 텍스트 파일로 받아요!(add 하기전 파일을 받을 수 있음)
git diff > changes.diff
```

## **변경사항 추가/커밋**

```cpp
text# 파일 추가
git add file.txt
git add .                      # 모든 변경
git add -A                     # 모든 변경+삭제 포함

# 커밋
git commit -m "메시지"
git commit --amend             # 최신 커밋 수정

# 스테이징 취소
git restore --staged file.txt
git reset HEAD file.txt

# 변경 취소 
git restore file.txt
git checkout -- file.txt
```

## **병합/충돌 해결**

```cpp
text# 브랜치 병합
git merge branch-name

# 충돌 해결 후
git add .
git commit -m "Merge conflict resolved"

# 리베이스 (선형 히스토리)
git rebase branch-name

# 리베이스 충돌 해결 후
git rebase --continue
git rebase --abort             # 취소
```

## **원격 저장소**

```cpp
text# 원격 추가
git remote add origin URL

#원격에 있는걸 로컬로 가져오고싶어요!
git switch -c 이름 --track origin/이름(같게)
예시 :  git switch -c "#12물리연결완성" --track origin/"#12물리연결완성"

# 원격 푸시
git push origin branch-name
git push -u origin branch-name # 처음 푸시

# 원격 풀 (fetch+merge)
git pull origin branch-name

# 원격 페치만(깃 데스크에 있는 그 버튼임)
git fetch origin

# 강제 푸시
git push --force-with-lease
```

## **히스토리 정리**

```cpp
text# 최신 커밋 되돌리기 (로컬)
git reset --soft HEAD~1        # 커밋만 취소
git reset --mixed HEAD~1       # 스테이징까지 취소
git reset --hard HEAD~1        # 완전 삭제

# 커밋 되돌리기 (히스토리 유지)
git revert HEAD

# 로그 확인
git log --oneline --graph
git log --oneline -10
```

## **워크플로우**

```cpp
text# 1. 최신 가져오기
git pull origin main

# 2. 새 브랜치
git checkout -b feature/작업명

# 3. 작업 후
git add .
git commit -m "feat: 작업내용"

# 4. 푸시
git push -u origin feature/작업명

# 5. PR 생성 (GitHub/GitLab 웹)
# 6. 병합 후
git checkout main
git pull origin main
git branch -d feature/작업명
```
