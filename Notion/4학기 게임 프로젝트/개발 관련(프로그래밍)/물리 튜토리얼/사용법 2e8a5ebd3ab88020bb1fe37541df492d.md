### 월드에서 물리 키는법

물리가 필요한 씬과 필요하지 않은 씬이 나뉩니다
그래서, 그걸 구분하기위한 컴포넌트가 있어요

**PhysicsSceneSettingsComponent << 월드에 이 컴포넌트를 붙여주세요
안붙으면 물리 시뮬 안돌아가거나 / 터질 수 있습니다**

월드 자체에 주인없는 오브젝트로 붙이면 됩니다(ECS구조)
물리 시스템 루프에서, 월드에 해당 컴포넌트가 있어야만 돌아가요(인식키같은거임)

- PVD가 뭔가요?
    
    엔비디아에서 제공하는 디버그 툴이에요

    ## 물리 관련 컴포넌트 사용 방법
    
    ### 1. 물리 컴포넌트 종류
    
    ### 기본 물리 컴포넌트
    
    - `src/PhysX/Components/Phy_SettingsComponent.h` - 물리 씬 설정 (중력, 레이어 등)
    - `src/PhysX/Components/Phy_RigidBodyComponent.h` - 리지드바디 (동적/키네마틱)
    - `src/PhysX/Components/Phy_ColliderComponent.h` - 기본 콜라이더 (Box/Sphere/Capsule)
    - `src/PhysX/Components/Phy_MeshColliderComponent.h` - 메시 콜라이더 (Triangle/Convex)
    - `src/PhysX/Components/Phy_CCTComponent.h` - 캐릭터 컨트롤러
    - `src/PhysX/Components/Phy_TerrainHeightFieldComponent.h` - 지형 HeightField
    - `src/PhysX/Components/Phy_JointComponent.h` - 조인트 (엔티티 간 연결)
    
    ### 2. 물리 컴포넌트 사용 방법
    
    ### 기본 사용법 (코드)
    
    ```cpp
    // 엔티티 생성
    EntityId entity = world.CreateEntity();
    
    // Transform 추가 (필수)
    auto& transform = world.AddComponent<TransformComponent>(entity);
    transform.SetPosition(0.0f, 5.0f, 0.0f);
    
    // 리지드바디 추가 (동적 물리 바디)
    auto& rigidBody = world.AddComponent<Phy_RigidBodyComponent>(entity);
    rigidBody.density = 1.0f;
    rigidBody.isKinematic = false;  // false = 동적, true = 키네마틱
    rigidBody.gravityEnabled = true;
    
    // 콜라이더 추가 (Box)
    auto& collider = world.AddComponent<Phy_ColliderComponent>(entity);
    collider.type = ColliderType::Box;
    collider.halfExtents = { 0.5f, 0.5f, 0.5f };
    collider.isTrigger = false;  // true면 트리거로 동작
    
    ```
    
    ### 에디터에서 사용
    
    1. 엔티티 선택
    2. 인스펙터에서 "Add Engine Component" → 물리 컴포넌트 선택
    3. 컴포넌트 파라미터 조정
    
    ### 3. 물리 컴포넌트 조합 예시
    
    ### 동적 리지드바디 + 콜라이더
    
    ```cpp
    // 떨어지는 박스
    EntityId box = world.CreateEntity();
    world.AddComponent<TransformComponent>(box).SetPosition(0, 10, 0);
    world.AddComponent<Phy_RigidBodyComponent>(box);  // 동적 바디
    world.AddComponent<Phy_ColliderComponent>(box);    // Box 콜라이더
    
    ```
    
    ### 정적 콜라이더 (RigidBody 없음)
    
    ```cpp
    // 바닥 (Static)
    EntityId floor = world.CreateEntity();
    world.AddComponent<TransformComponent>(floor);
    auto& col = world.AddComponent<Phy_ColliderComponent>(floor);
    col.type = ColliderType::Box;
    col.halfExtents = { 10.0f, 0.5f, 10.0f };
    // RigidBody 없으면 자동으로 Static Actor로 생성됨
    
    ```
    
    ### 캐릭터 컨트롤러
    
    ```cpp
    // 캐릭터
    EntityId character = world.CreateEntity();
    world.AddComponent<TransformComponent>(character);
    auto& cct = world.AddComponent<Phy_CCTComponent>(character);
    cct.radius = 0.35f;
    cct.halfHeight = 0.9f;
    cct.desiredVelocity = { 5.0f, 0.0f, 0.0f };  // 이동 속도
    
    ```
    
    ### 조인트 (두 엔티티 연결)
    
    ```cpp
    // 조인트로 연결
    EntityId jointEntity = world.CreateEntity();
    auto& joint = world.AddComponent<Phy_JointComponent>(jointEntity);
    joint.type = Phy_JointType::Revolute;  // 회전 조인트
    joint.targetName = "TargetEntityName";  // 연결할 엔티티 이름
    
    ```
    
    ### 4. 물리 시스템 초기화
    
    ### 필수 설정
    
    ```cpp
    // 씬에 Phy_SettingsComponent 추가 (물리 활성화)
    EntityId settingsEntity = world.CreateEntity();
    world.AddComponent<Phy_SettingsComponent>(settingsEntity);
    // PhysicsSystem이 자동으로 물리 월드 생성
    
    ```
    
    ### PhysicsSystem 업데이트
    
    ```cpp

    // - 컴포넌트 변경 감지
    // - Game → Physics 동기화
    // - Physics → Game 동기화
    // - 이벤트 처리
    
    ```
    
    ## 컴퓨트 이팩트 사용 방법
    
    ### 1. 컴퓨트 이팩트 컴포넌트
    
    - `src/Components/ComputeEffectComponent.h` - 컴퓨트 이팩트 컴포넌트
    - `src/Rendering/ComputeEffectSystem.h/cpp` - 컴퓨트 이팩트 시스템
    - `src/Rendering/ShaderCode/ComputeEffectShader.h` - 컴퓨트 셰이더 코드
    
    ### 2. 컴퓨트 이팩트 사용 방법
    
    ### 기본 사용법 (코드)
    
    ```cpp
    // 엔티티 생성
    EntityId effectEntity = world.CreateEntity();
    
    // Transform 추가 (위치 소스로 사용)
    auto& transform = world.AddComponent<TransformComponent>(effectEntity);
    transform.SetPosition(0.0f, 2.0f, 0.0f);
    
    // 컴퓨트 이팩트 추가
    auto& effect = world.AddComponent<ComputeEffectComponent>(effectEntity);
    effect.enabled = true;
    effect.shaderName = "Particle";  // 또는 "Sparks", "Smoke", "Vortex", "Snow", "Explosion"
    effect.useTransform = true;  // Transform 위치 사용
    effect.localOffset = { 0.0f, 0.0f, 0.0f };
    effect.radius = 0.5f;
    effect.color = { 1.0f, 1.0f, 0.0f };  // 노란색
    effect.sizePx = 6.0f;
    effect.intensity = 1.0f;
    
    ```
    
    ### 사용 가능한 파티클 타입
    
    - `"Particle"` - 기본 파티클
    - `"ParticleEffect"` - 기본 파티클 (별칭)
    - `"Sparks"` - 스파크
    - `"Smoke"` - 연기
    - `"Vortex"` - 소용돌이
    - `"Snow"` - 눈
    - `"Explosion"` - 폭발
    
    ### 에디터에서 사용
    
    1. 엔티티 선택
    2. 인스펙터에서 "Add Engine Component" → "ComputeEffectComponent" 선택
    3. 파라미터 조정:
        - Particle Type: 파티클 타입 선택
        - Use Transform: Transform 위치 사용 여부
        - Local Offset: Transform 기준 오프셋
        - Radius, Color, Size: 이미터 파라미터
        - Gravity, Drag, Life: 물리/수명 파라미터
    
    ### 3. 컴퓨트 이팩트 시스템 초기화
    
    ```cpp
    // Engine 초기화 시
    ComputeEffectSystem computeEffectSystem(renderDevice);
    computeEffectSystem.Initialize(width, height);
    
    // 매 프레임 렌더링 시
    computeEffectSystem.Execute(world, viewProj, cameraPos, depthSRV, deltaTime);
    
    // 출력 텍스처 가져오기
    ID3D11ShaderResourceView* effectSRV = computeEffectSystem.GetOutputSRV();
    // 이 SRV를 포스트 프로세스로 사용
    
    ```
